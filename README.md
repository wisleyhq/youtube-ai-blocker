# Lista compartilhada (dados)

Esta branch guarda só a lista compartilhada da extensão
[Bloqueador de Vídeos de IA para YouTube](https://github.com/wisleyhq/youtube-ai-blocker).

- `lists/ai-list.json`: vídeos com o selo oficial "Criado com IA" do YouTube,
  agrupados por canal.
- Quem grava aqui é o robô do repositório, depois de conferir cada vídeo no
  YouTube. Não edite à mão.
- Para contribuir, use a aba **Compartilhar** da extensão.

O código da extensão fica na branch `main`.
